# physics-interactive-sims

單檔、零建置的物理互動模擬網頁。直接用瀏覽器開啟 `sims/*.html` 即可（efield3d 需連網載入 three.js，部分頁面的字型來自 Google Fonts，離線會退回系統字型）。每個作品的物理模型、操作與驗證見 `docs/`。

| 作品 | 主題 | 說明 |
|---|---|---|
| [binary_star](sims/binary_star.html) | 古典力學 | [docs](docs/binary_star.md) |
| [black_hole_geodesic](sims/black_hole_geodesic.html) | 廣義相對論 | [docs](docs/black_hole_geodesic.md) |
| [black_hole_schwarzschild](sims/black_hole_schwarzschild.html) | 廣義相對論 | [docs](docs/black_hole_schwarzschild.md) |
| [corona](sims/corona.html) | 高壓／靜電 | [docs](docs/corona.md) |
| [cyclotron_radiation](sims/cyclotron_radiation.html) | 電磁／輻射 | [docs](docs/cyclotron_radiation.md) |
| [efield3d](sims/efield3d.html) | 靜電學（3D） | [docs](docs/efield3d.md) |
| [elastic_collision_2d](sims/elastic_collision_2d.html) | 力學 | [docs](docs/elastic_collision_2d.md) |
| [equivalence_principle](sims/equivalence_principle.html) | 廣義相對論 | [docs](docs/equivalence_principle.md) |
| [moving_charge_field](sims/moving_charge_field.html) | 電動力學 | [docs](docs/moving_charge_field.md) |
| [skin_effect](sims/skin_effect.html) | 電磁波 | [docs](docs/skin_effect.md) |
| [dewpoint_psychrometric](sims/dewpoint_psychrometric.html) | 熱力學 | [docs](docs/dewpoint_psychrometric.md) |

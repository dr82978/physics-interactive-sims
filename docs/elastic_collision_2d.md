# 二維彈性碰撞（elastic_collision_2d）

[開啟](../sims/elastic_collision_2d.html)

## 內容
兩個帶自旋的圓盤球在有牆的箱內碰撞，即時顯示動能、動量與角動量。

## 物理模型
- 衝量法：法向 j_n = −(1+e)Δv_n/(1/m₁+1/m₂)；切向有庫侖摩擦（|j_t| ≤ μ|j_n|），並與自旋耦合。轉動慣量 I = ⅖mr²（實心球）。
- 牆面與球—球共用恢復係數 e；牆面無摩擦。
- 角動量對左下角原點計算：軌道 m(r×v) + 自旋 Iω；角速度逆時針為正。

## 驗證
碰撞前後（牆面未介入）動量守恆，角動量守恆至 10⁻¹³；e=1、μ=0 時動能嚴格守恆；μ>0 時因滑動摩擦略減（約 0.05%）。

## 操作
兩球可各自啟用／停用；改參數離開欄位即重新模擬；空白鍵暫停。子步長依速度自適應，避免高速穿透。

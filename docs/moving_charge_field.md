# 運動電荷的場（moving_charge_field）

[開啟](../sims/moving_charge_field.html)

## 內容
靜止觀察者看到一個沿 +x 運動且同向加速（a∥v）的點電荷：電場線、磁場與輻射角分佈。

## 物理模型
- 速度場：E ∝ (1−β²)/(1−β²sin²θ)^{3/2}/r²（θ 自運動軸量起）；B = β×E/c。橫向 ×γ、縱向 ÷γ²。
- 場線為等通量配置，滿足 tanθ = γ tanθ₀，高速時被壓成垂直運動方向的餅狀。
- 輻射（a∥v）：dP/dΩ ∝ sin²θ/(1−β cosθ)⁵；峰值方向 cosθ = (√(1+15β²)−1)/(3β)；總功率 P = q²a²γ⁶/(6πε₀c³)。

## 注意
場線採等速場；加速度對場線形狀的修正在實驗室量級可忽略，輻射以自動縮放的波瓣呈現方向與形狀。

# 史瓦西黑洞模擬器（black_hole_schwarzschild）

[開啟](../sims/black_hole_schwarzschild.html)

## 內容
輸入天體質量 M 與半徑 R，判斷是否落入史瓦西半徑而成為黑洞，並列出相關物理量。

## 物理模型
r_s = 2GM/c²；R ≤ r_s 即黑洞。輸出：緊緻度、表面逃逸速度、重力時間膨脹 √(1−r_s/R) 與紅移、平均密度、表面重力、光子球 1.5 r_s、ISCO 3 r_s、陰影半徑 (3√3/2)r_s、霍金溫度與蒸發壽命。

## 操作
對數滑桿或直接輸入（如 1.989e30）；七個預設（地球、太陽、白矮星、中子星、恆星級黑洞、人馬座 A*、M87*）。

## 注意
- 畫面以對數映射呈現 R 與 r_s 的相對關係，並非線性真實尺寸；背景星場用點質量透鏡近似光線偏折。
- 霍金溫度與壽命對非黑洞標註「若塌縮成黑洞」，僅供參考。

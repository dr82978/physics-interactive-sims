# 古典力學雙星運動（binary_star）

[開啟](../sims/binary_star.html)

## 內容
牛頓重力下的兩體問題：設定兩星質量、初速、方向與間距，即時積分並與解析軌道比對。

## 物理模型
- 化約為約化質量 μ 繞質心的單體運動；由比能 ε 與比角動量 h 判定圓／橢圓／拋物線／雙曲線，離心率向量決定近星點方位。
- 顯示 a、b、p、r_min、r_max、週期 T、偏轉角 δ、總能 E、角動量 L。
- 積分：速度 Verlet（辛），子步長取動力學時標的 1%，近星點自動加密。

## 操作
四個預設（近圓、橢圓、拋物線、雙曲線）；調參數自動重置；空白鍵暫停。速度箭頭長度正比於速率；非束縛軌道自動縮小視野；左下為比例尺。

## 驗證
離心率 0.92 軌道跑兩個週期：ΔE/E ≈ 2×10⁻⁵，L 守恆至 10⁻¹⁵。預設組態（3 M☉、1 AU：v_circ≈51.6、v_esc≈73.0 km/s）分類正確。

## 限制
質點、純牛頓、無廣義相對論；軟化長度 0.004 AU 避免極近距離發散。

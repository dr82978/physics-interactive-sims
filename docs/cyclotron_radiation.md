# 磁場中的電荷：迴旋／同步／軔致輻射（cyclotron_radiation）

[開啟](../sims/cyclotron_radiation.html)

## 內容
單位電荷由場外直線射入圓形均勻磁場，觀察旋轉、輻射，以及阻尼與軔致輻射造成的失能螺旋。

## 物理模型
- 相對論運動：r = γmv/qB，ω = qB/γm；旋向由 q v×B 決定（電子與質子相反，並受 B 入／出紙面影響）。
- Larmor–Liénard：P = γ⁴q²a²/(6πε₀c³)；基頻 ħω、臨界 ħω_c = 1.5ħγ³c/r、束射半角 1/γ。
- 軔致輻射為示意模型（制動加速度取向心加速度，P_b = γ²P）；失能速度已加速顯示，真實時標見 τ = E/P。
- 無耗散時，外來粒子必離開有限磁場區；開啟阻尼或軔致才會被捕獲。

## 操作
速度（0→c）、B（0→10 T）、電子／質子、B 方向、兩個效應開關；空白鍵暫停、R 重新入射。

## 驗證
四種「電荷 × B 方向」組合的旋向全部符合 q v×B。

# 趨膚效應模擬器（skin_effect）

[開啟](../sims/skin_effect.html)

## 內容
平面電磁波垂直由介質 A 入射介質 B，顯示反射、透射與振幅降至 1/e 的趨膚深度 δ。

## 物理模型
- 時間因子 e^{−iωt}；k² = ω²με + iωμσ，k = α + iβ，δ = 1/β。保留完整 ε_c = ε + iσ/ω，良導體、介電質與過渡區皆有效。
- 本徵阻抗 η = ωμ/k = √(μ/ε_c)；r = (η_B−η_A)/(η_B+η_A)，t = 1+r。A 區為入射＋反射的部分駐波，B 區為衰減透射波。
- 滑桿皆為對數刻度（f：1 Hz–100 GHz；σ：10⁻⁸–10⁸ S/m）；9 個材料預設（水、土、海水、石墨、鋼、鋁、銅、鐵）。

## 注意
- 良導體的 |t| 極小（接近全反射）；預設開啟「B 區放大至介面振幅」，才看得到衰減曲線，並標示放大倍率與實際 |t|。
- 近似：無限平面波、垂直入射、材料參數與頻率無關、線性。動畫時間流速僅供觀看，空間衰減為實際物理。

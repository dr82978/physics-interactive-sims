# 露點模擬與濕空氣線圖（dewpoint_psychrometric）

[開啟](../sims/dewpoint_psychrometric.html)

## 內容
調整溫度與總水氣含量（g/m³），看相對濕度、露點、凝結量，並在濕空氣線圖上標出狀態點。

## 物理模型（1 atm）
- 飽和水氣壓（Magnus／Tetens）：e_s = 6.1078·exp(17.27T/(T+237.3)) hPa。
- 水氣密度：ρ_v = 216.5·e/(T+273.15) g/m³；露點由 e 反解。
- 改變溫度時水氣分壓 e 保持不變（露點不變）；超過飽和的部分凝結為液態水，回溫會再蒸發。

## 注意
0 °C 以下以過冷水計，未區分冰面飽和。左側容器：虛線框為最大容納量。圖表與版面支援手機。

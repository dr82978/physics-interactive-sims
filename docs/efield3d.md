# 3D 靜電場觀測儀（efield3d）

[開啟](../sims/efield3d.html)（需連網載入 three.js r128）

## 內容
均勻外場 E₀（−z）中放入導體或介電質物體，3D 顯示電場流線，顏色為 |E|/E₀。

## 物理模型
有限差分解 ∇·(ε∇φ)=0（SOR），面 ε 取調和平均；導體 φ=0，外邊界 φ=E₀z；E = −∇φ，RK4 沿單位場積分流線。形狀：實心／空心球、立方體、圓柱（橫置或直立）、雙層球與雙層圓柱。

## 對照理論（無限域）
導體球極點 3E₀；導體圓柱側緣 2E₀；介電球內 E/E₀ = 3/(εᵣ+2)；介電圓柱（橫置）2/(εᵣ+1)；導體空腔內 E=0。

## 驗證
畫面右下 HUD 顯示數值解的中心與最大 |E|/E₀（導體球：中心 0.000，最大 2.81，理論 3），因計算域有限會略有偏差。

## 操作
拖曳旋轉、滾輪／雙指縮放；解析度可選 40³ 或 56³。
